# CP473 private Type3 .OPT section preparation

The original Type3 `.OPT` writer is byte-bound by CP465. CP473 independently bound seven further fixed C-string literals (77 bytes, zero mismatches), including the `DOE_PAR` count label, the numbered-row value suffix, both `REGIONS` headers and the `Opt`, `/`, `.GEO` composition tokens. A separate PE verifier resolved the normal `SfMoDoeManager` vtable `+0x1c0` slot to `0x14091bcb0` and byte-compared its complete 237-byte/57-instruction body with zero mismatches. That method reindexes every manager variable before filtering null-link variables into a temporary list; the writer consumes the list size and emits numbers 1 through that count, not list elements.

CP473 adds private typed-event planners for the prepared count and region sections. The count planner preserves label/int/`endl`, each index/fixed-suffix/`endl`, and the final standalone `endl` even for zero or negative prepared counts. The region planner preserves the zero-count literal/`endl` or positive count header/int/`endl` followed by ordered prepared QString row/`endl` events. The original QString glue helper copies RDX and appends R8, so the successful prepared row is `Opt/` + region name + `.GEO`; `analysis/cp474-opt-region-helper-order.md` records the correction of an earlier reversed interpretation. A parser-to-DefOpt view test covers one admitted BOM-free ASCII/LF/final-LF profile. A direct existing-manager regression now checks that linked as well as unlinked variables are reindexed when `unlinkedVars()` is called. The code already implemented that scan; it was not duplicated.

Independent source reviews found no blocking mismatch. Four focused targets passed, followed by one source/binary-bound grouped build and 385-test launcher: 378 clean, six logged-gap and one logged-difference cases, no skips, incomplete outputs or fixture changes. Source SHA-256 was `0368cdcaf6f5fa68284273a991ff571cea3c1b4d818d12b05b409e4cdc701aad` over 3,608 files. Historical Save remains 93 SAME/five DIFF. The m2m C ABI and public Type3 guard remain unchanged.

These planners are still isolated from the actual private Save attempt. In particular, the count planner accepts a supplied count and does not call the manager, and the region planner precomputes prepared row values. CP474 must invoke the existing manager scan at its original late position and emit region rows lazily if it is to preserve getter/failure timing. Neither planner establishes native Qt allocation, QTextStream encoding/formatting, QFile effects, physical bytes or public Type3 Open→Save→Close parity. No original executable or GUI control was used.
