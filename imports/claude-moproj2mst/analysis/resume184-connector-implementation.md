# CP184 connector implementation

CP184 adds only `mov rbx,[rsp+0x48]` over `[0x131235,0x13123a)` and stops at `BeforePrivateStackAdjustment`, RVA `0x13123a`. The CP183 diagnostic stop remains ordinal five; ordinal six is the new default terminal boundary. Ordinals zero through four retain their prior instruction budgets. Invalid budgets refuse before allocation.

The retained `SavedTaskRbx` contract derives symbolic entry-stack S and the caller task identity when the qualified initializer frame is created. It records ledger weak ownership/control block, Report ordinal, task/private identities, selected Qt module hash, initializer entry and caller call/return RVAs, RSP displacement `-0x38`, save slot `S+0x10`, and equivalent displacement `RSP+0x48`. The entry stack is symbolic: no numeric native address, saved RDI assumption, or native memory capture is introduced. Retained contracts are validated rather than repaired, including across diagnostic rewinds.

The instruction publishes only `restoredTaskRbxIdentity` and the new phase through nonthrowing assignments. RAX remains the allocation-bound `returnPrivateIdentity`; the CP182 `flags20Eax` expression and private+0x20 store remain historical provenance. The restored RBX names the pending task rather than its private allocation. Existing full owner/root/version/sparse/expression qualifications run at both the CP183 predecessor and new terminal stop. Saved ledger identity is checked using both pointer and shared ownership identity. Premature restored results refuse at earlier phases, and RAX tokens remain forbidden before the CP183 phase.

Full-frame snapshot helpers now include the symbolic stack contract, its weak ownership identity, and the restored result. Existing default-terminal expectations advance to the CP184 boundary, while all dedicated CP183 tests retain ordinal five. Earlier diagnostic rewinds explicitly clear the restored result alongside RAX/flags observations and retain their valid symbolic prologue contract. Focused additions cover a full predecessor snapshot comparison, identity-role preservation, same/different-key terminal reentry, 34 predecessor/terminal corruption variants, ordinal-zero-through-five rewind/resume, and corruption retained at an earlier diagnostic stop. Invalid-budget coverage now begins at seven because six is admitted.

Stack adjustment, RDI restore, RET, caller cursor advancement, QObject/base completion, both backlinks, and cache/prototype completion remain unavailable. This implementation uses the qualifications in `resume184-connector-next.md` and its independent static review; it does not establish live stack observations or complete native behavior.
