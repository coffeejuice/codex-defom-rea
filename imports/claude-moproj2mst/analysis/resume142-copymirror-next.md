# CP142 CopyMirror property caller and consumer crosswalk

## Finding

The retained original source closes a concrete CopyMirror writer-prefix omission that CP141's recommendation had not seen: native writer `0x140e24e80` calls the matched properties object's virtual `+0x60` method (`0x140e2d230`) **before** entering block writer `0x140e24f60`. Candidate `CopyMirrorClass::writeMst` skips that call. A narrow private correction is source-closed: for a matched `CopyMirrorProps`, call its existing `propsToEngine(prj, *item)` before `writeBlock`. Keep this private writer-only change separate from public registration/Open admission.

## Bounded original/candidate crosswalk

1. `evidence/gui_mo/s1/opw_d0.c`, `FUN_140e24e80 @ 0x140e24e80`, resolves properties with `0x1405ef320(self,item)` and a dynamic cast to type descriptor `0x1439c1d88`. When nonnull, it calls the object's vtable slot `+0x60`, then calls `FUN_140e24f60` with that same properties pointer. This is direct writer-body evidence; the compact contract is also recorded in both `evidence/gui_mo/s1/s1-04/spec.md` §5 and the imported `source/docs/re/moproj2mst/s1-04/spec.md` §5.
2. `evidence/gui_mo/s1/mdt/L5/s0.c`, `FUN_140e2d230 @ 0x140e2d230`, bounds the mutation: get the operation model; return 0 if unavailable; walk objects 1..count; skip null/kind-7; copy `ConvertData.upAxis` to WPAXIS and `+0x2c38`, `conType` to `+0x2be8`, then either revolution (`+0x2bf0`, `+0x2bf8`) when type is 1 or extrusion (`+0x2c10`, `+0x2c18`) otherwise. The wrapper's call is unconditional on the `onlySim` block filter; its return is ignored before the writer body proceeds.
3. Candidate `src/ops/copymirror.cpp::CopyMirrorClass::propsToEngine` already dispatches `g_l5Slots.cmPropsToEngine`, and `src/engine/l5_slots.cpp::copyMirrorPropsToEngine` delegates to this same source-qualified `convertPropsToEngine` body. But candidate `writeMst` at `copymirror.cpp` around lines 114–121 only casts `CopyMirrorProps` and calls `writeBlock`; its comment says the `+0x60` update is not ported. The body method around line 126 increments `sim`, then applies the `onlySim` filter. Therefore the missing call belongs before `writeBlock`, not inside the filtered body.
4. The `writeBlock` sequence starts with SIM/DBREAD/control/material/mesh settings and then `emitObjects`; this makes the updated model available to the writer's downstream consumers. The retained static body establishes the property mutation and its order, but this bounded evidence does **not** establish that any particular emitted byte changes for a given nondefault property. Do not report byte sensitivity or raw-output parity without a field-read trace or paired case.

## Status and smallest next implementation/test

- **Settled:** Original writer calls `Properties vt+0x60` before `0x140e24f60`; the slot's model mutation and object-kind filter are source-bound.
- **Confirmed candidate omission:** `CopyMirrorClass::writeMst` omits that prefix call despite already having the equivalent override and installed slot.
- **Private source cut closed:** call `propsToEngine(prj, *item)` in the matched-property branch immediately before `writeBlock`; retain its ordering even when `onlySim` later excludes output. Use a valid constructor-produced `CopyMirrorProps`/`ConvertData`; do not widen malformed-owner behavior here.
- **Public reachability remains unsupported:** CopyMirror is still not registered in the current registry (`src/model/registry_rescue.cpp` explicitly notes it is not registered), and retained case notes say there is no corpus project. This private correction does not authorize registration or make a public lifecycle test possible.
- **Smallest focused regression:** use a directly constructed `CopyMirrorClass` with a real Project/operation model containing one non-kind-7 object and nondefault `ConvertData`. Call `writeMst` with an `onlySim` value that suppresses the block; assert the model's WPAXIS, `+0x2c38`, `+0x2be8`, and selected dimension pair reflect the property values while output stays empty and `sim` advances as before. This specifically distinguishes the native pre-filter mutation from the candidate omission. Keep a kind-7 object unchanged. Existing `tests/p12/test_p12_writers.cpp::testCopyMirror` verifies block text and sim count but supplies no operation model/nondefault property and therefore does not cover this mutation.

CP141's conclusion that the native Open loader has no recovered property-to-engine call remains unchanged. Its separate statement that no writer call is established is superseded by the direct `0x140e24e80` body above. This read-only static-source audit does not execute the original or candidate, and does not assert downstream bytes. No source, build, GUI, or mutable REA action occurred.
