Narrow friendship permits that Session boundary; public constructors, allocation-store APIs, Native profile, task keys and parsed DOE projection do not issue the qualification. Binding requires pristine store counts, no initialized factory/pending occurrence and exact canonical root pairing.

The factory retains independent Session eligibility, the immutable capability, an independent weak witness of its issued control block, non-reissuable frame issuance history and the exact frame binding. ## Independent-review correction: private allocation lifetime

The source review in `resume196-report-null-source-review.md` correctly blocked the initial source on address-only private-allocation identity. A replacement private object could occupy the same storage with copied model fields, while the frame/token witnesses remained unchanged. The earlier different-address replacement test did not cover that case.

`SparseQObjectPrivate` now owns a separately generated allocation-occurrence witness. The reusable occurrence type is at `PendingTaskPrototype` scope, with the existing frame alias retained. Default/copy construction produces a new identity; a move preserves the independently prepared occurrence. The immutable issued binding stores the original private occurrence and admission validates its exact pointer/control-block identity alongside the raw private address. This check follows existing private address/size checks and precedes existing frame/token witness checks, preserving prior refusal order. Complete snapshots include both the live private occurrence and the binding's occurrence.

A deterministic regression copies the qualified private values, ends the original object lifetime with `std::destroy_at`, and nonthrowingly move-constructs the prepared replacement into the same owned storage with `std::construct_at`. It proves the raw address, every sparse model field and all four shared-root ownership bindings remain equal while the occurrence changes. The original witness is deliberately kept alive, so rejection proves identity discrimination independently of expiry. It then requires complete damaged-state/count snapshot equality for all requested keys under budgets 0 and 17. The prior different-address replacement case remains. A compile-time assertion covers nonthrowing private-state move construction. This correction was statically checked only; root must rebuild, rerun validation and re-review before freezing.
