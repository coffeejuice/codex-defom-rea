# CP70 high-version cached id0x0b normal return

The actual-N-owner high-version path now continues after its real COW/table
prefix only when the actual MAR header index is bounded, signed id limit is
above11 and actual id0x0b cache marker is nonzero. The native reader's false
return is ignored by outer which0; coordinate readiness can therefore continue
to connectivity without replaying the first coordinate dispatch. Cache misses
and other unqualified reader states remain pending with their committed effects.
