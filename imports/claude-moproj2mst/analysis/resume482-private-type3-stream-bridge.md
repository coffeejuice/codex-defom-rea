# CP482 private typed Type3 Stream bridge

The source-backed private Type3 `.OPT` event projection now has an opt-in sink that forwards literal, integer, binary64 double, QString and endl calls to the shared `mst::Stream` on a Text-mode `mst::FileDevice`. It accepts an explicit host-selected codepage and a UTF-8 path. The device opens before the Stream is constructed; failed open records a diagnostic without constructing a stream. Explicit file close occurs while the Stream remains alive, allowing the aboutToClose callback to flush pending text. The sink's opaque-fragment method returns false, and the separate typed-profile gate refuses the unsupported generic profile before opening or truncating the destination. The typed attempt still returns its recovered ordinary false result.

Focused tests cover CP1252-selected bytes including U+00E9, Text-mode CRLF, pending close-time flush, idempotent close, non-ASCII filename conversion, failed-open diagnostics, a sentinel destination unchanged by pre-open refusal, and successful typed-manager routing with prepared opaque fragments excluded. These are candidate encoding tests; CP479 did not bind the original writer's actual occurrence codec, so they do not assert original physical-byte equality. The bridge is private and does not admit public Type3 Save or prove exception unwind, native owner association, or Close cleanup.

Independent review found and closed four issues before final validation: ineffective post-open opaque refusal, missing output-byte assertions, ambiguous narrow path conversion, and Stream construction on failed open. The first source-stable CP482 build passed, then a test-path UTF-8 correction was independently reviewed and source-stable `analysis/cp482r-build.json` passed focused and full build. One bound full launcher registered 387 tests: 380 clean, six with logged gaps, one with a logged difference, zero failed/skipped/incomplete, no fixture changes.
