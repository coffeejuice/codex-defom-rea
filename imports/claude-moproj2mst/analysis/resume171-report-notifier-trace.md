# CP171 Report Save notifier to MainWindow step guard

## Result and scope

The retained original establishes a **conditional direct call chain** from Report document default Save to a registered `SfMainWindowBase` slot whose first nonnull-step effect is a request to bind `W+0x48` to the emitted `SfStepData*`. The Report emitter uses the same global notifier and identical signal bytes as the qualified MainWindow registration. This resolves one named receiver candidate left open in CP169. It does **not** establish that the receiver was registered, live, selected and invoked during a particular Report Save, that the QPointer guard bind returned normally, or that Open, Save and Close share one document/main generation. No new public source cut is admitted. The missing witness is specified below.

This is a read-only static investigation of original **DEF_GUI_MO_64 v11.0.2**, SHA-256 `fd8ae1f8dd50d068267b3b7e49efdf11eaa178889131e59ec4b6f8de64725acc`, preferred base `0x140000000`. Original addresses below are preferred VAs; the corresponding RVA is VA minus that base. PE range hashes are for half-open mapped bytes, not proofs of runtime occurrence or complete logical callees. The retained decompiles and CP152/169 source qualification, not a new live REA result, govern the interpretations.

## Missing witness and source boundary

The smallest missing witness for a **Report Save W+0x48 effect** is one natural, same-process and same-generation original Report Save occurrence that binds: current Report D and its `0x14064c030(D)` W; W's actual table and `+0x778/+0x268` results; both ordered `0x140cf94f0` returns and the first typed S; N suppression and `+0x90` before/after; the keyed receiver list at this emission, including actual W, weak validity and any earlier callbacks; selected direct `invokeMethod` entry/normal return; the slot's current W/S; and `0x140cbc920(W+0x48,S)` entry/normal return with W+48 before/after. Null, changed-table, suppressed, absent-receiver, failed-invoke or interrupted paths must remain their actual outcomes. A separate CP152 Boolean invocation cannot supply this Save-specific owner/delivery relation. For full public parity, the same occurrence must additionally cover Report Open document publication, later Save task/DOM/file effects and accepted Close; CP169 describes those wider dependencies. The parent repository's supported GUI-control release/receipt gate remains in force for an original GUI run.

The converter's `ConversionSession` owns canonical `doe::SessionNotificationState` (`source/apps/moproj2mst/include/m2m/doe_session_notifications.hpp`) but currently projects other registrations, not this MainWindow receiver and W+48 state. `source/apps/moproj2mst/src/ops/report.cpp` refuses Report Open at document access, `src/engine/save_current.cpp` refuses Report `vt+0x68`, and `src/engine/report_document_slot.cpp` is only a diagnostic initial token. A detached notifier/W helper or one assumed registration would not advance the actual public Save path. **There is no source-ready public Report cut from this static join alone.** Keep all three guards. A later bounded source cut, after the owner/delivery witness, belongs on the actual Session application/MainWindow owner and existing notifier; it may commit the notifier gate/reset and qualified W+48 guard effect while stopping before `0x140c7b310` and subsequent callbacks.

## Focused tests for an admitted later cut

Use the actual `ConversionSession` notifier and one owner-bound W/S generation, not independent observation tokens. Test the emitter inequality and two-read distinction; null main/`+0x778` or equal second read leaves notifier and W unchanged. Suppression preserves `N+0x90` and W+48. Unsuppressed entry resets the canonical `N+0x90` before key/list delivery, with expired weak entries handled in source order and no invented receiver. Null S preserves an existing W+48. Nonnull S commits W+48 only after qualified guard return, then stops before accessor/scalar/UI effects; a guard refusal retains its prior value. Reject stale W table, changed W/S generation, absent registration, incompatible method and interrupted direct invocation without claiming slot completion. Reentry must not replay an already committed reset or bind. Keep the Report Open/Save/Close public refusal tests and focused Report/notifier/Close suites, then use the normal source-stable full/freeze gate. These are prospective tests; none ran in this read-only pass.
