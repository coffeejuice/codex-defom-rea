## Precise missing static evidence

The retained records inspected here lack an immutable writer/xref receipt identifying a **non-null** node-owner assignment for this optional mesh. Needed evidence is the original target identity, bounded instructions/decompilation with the actual store to node-set `+0x130` (mesh `+0x138`), its incoming owner value and lifetime/type, the matching `u138` setter/value, and exact caller/data-flow xrefs proving the receiver is the `OBJ_MESH2D` published at this cross-section's `+0x28`. A generic node-set setter name, constructor null store, scalar dimension setter, or main-object node-set owner attachment is insufficient.

If the creator intentionally retains a null owner, the equally discriminating alternative is its exact creator/copy/read occurrence with incoming source identity, positive node/element counts, and coordinate/connectivity allocation/publication before the viewer getters. The inspected copy bodies establish possible mechanics but leave their real source population/caller unbound. No optional-mesh-specific read snippet or exact producer xref was qualified by the reviewed records. This is a limit of this bounded retained evidence review, not an absence claim about the binary or all stored artifacts.

A writer/creator edge still needs a positive existing fixture with independent literal effects before production implementation. Main-object node sets and recovered getter bodies remain outside this assignment. No synthetic owner was created.
