## Green receipts and what they establish

`wave3-checkpoint57-validation.json` records 181 registered tests, 174 clean passes, 6 gap-qualified passes, 1 diagnostic-difference pass, and zero test failures. That confirms the tested candidate contracts for this source snapshot. It does not close source-level guards or objective gates: the same receipt says historical oracles are not fresh original sessions; `s.save_folder` is diagnostic and does not fail on folder differences/refusals; `g0.abi` accepts either success or unsupported; and historical results remain 93 `SAME` / 5 `DIFF`. The test suite contains helper and model tests, not a fresh original Open→Save→Close acceptance run.

The checkpoint57 validation lists the remaining differences explicitly: A:RS_55, DOE B120/B121/B122, and B98. `takeover-state.json` still has R300, RDOE, RBOOL, RGEOM and RINHERIT as partial/incomplete; the Boolean bridge does not update the original timer evidence, the DOE owner interface remains absent, and PPV guards remain. No completion claim follows from the aggregate exit code.

## One safe next edge

Take the paired **PPV root-only Save refusal** edge before enabling PPV Open. In `save_current.cpp`, establish and test the precise condition where the native writer would be reached with shared/root PPV entries but no local `recoveryB` points. The current candidate guard is local-list-oriented; a root-only mutation from predecessor Open must not pass through KEY Save while silently omitting the shared PPV file. The native writer receipt (`resume57-ppv-writer.md`) shows the writer's shared count/emission depends on shared-list and flags owners, while its output helper is not wired into `save_current.cpp`.

The smallest safe candidate action is to add a regression proving that this unsupported root-only state refuses **before any Save file effects**, without changing the writer or public loader path. Only after that guard is validated should the implementation consider the native writer call with actual root and flag owners. This is source-local and does not require GUI control, a mutable REA session, or assuming original output for malformed flag lengths. It protects an observable candidate state while preserving public PPV Open/Save refusal.
