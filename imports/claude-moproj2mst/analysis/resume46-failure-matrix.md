## Smallest independent regression fixture

Add one isolated **ordered Save failpoint fixture** at the native coordinator seam (no original application run required). Start from one successfully opened, disposable project with an eligible Boolean operation and an eligible DOE study. Inject failures by destination at the physical-I/O boundary and record ordered events plus surviving bytes/statuses. Keep it as one fixture harness with parameterized failpoints:

1. Fail the final MST open. Assert no MST generator or Boolean open/write event occurs; assert the permitted study follow-up still occurs; assert earlier stages and returned native/adapter statuses are recorded separately.
2. With MST open succeeding, fail BWZ open. Assert INI is still attempted, then MST generation continues; preserve the original helper return rule (BWZ result) independently of the ignored caller result.
3. Repeat with INI open failing. Assert BWZ bytes survive, MST generation continues, and no parent directory/temp/rename side effect is introduced by the native path.

This is the smallest independent fixture because one recorder/failpoint seam can distinguish the two critical gates and ordering branches without conflating operation serialization or relying on successful output equality. Use candidate-only filesystem cases for the failed-open residue after the recorder contract passes. Do not include stream short-write/CloseHandle injection in this first fixture: the retained receipts mark those original OS outcomes as not dynamically established. Open and Close still need their own independent evidence/fixtures; this Save fixture cannot close those gaps.
