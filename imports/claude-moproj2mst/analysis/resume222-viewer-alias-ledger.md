# Resume 222: viewer alias and lifecycle ledger

Scope: converter-only static inventory of retained raw `GuiModel`-owned addresses in viewer, scene, geometry temporary-prefix, and DOE slice paths. This is an alias ledger, not a claim that one pointer substitution closes the lifetime surface. No source behavior was changed.

## Findings

| Retained value / path | Current lifetime handling | Invalidation or gap | Needed opaque API and focused test |
|---|---|---|---|
| `View::ownerModel` (`viewer.cpp:273-274`) | `GuiModelGuard`, independent of QObject parent; lookup is guarded. | Guard addresses model death, but does not establish that cached step/object/array members elsewhere remain valid after reset/reload. | Keep model identity opaque and resolve each child on use; test model destruction and same-address replacement. |
| Geometry temporary-prefix binding: `Storage::model`, raw `step`, `db`, `reader` (`geometry_temp_prefix.cpp:13-21`); copied at `52-55`; used by `preparedGeometryTempPrefix` and `attempt` (`72-93`). | Guarded model plus identity comparisons for step/db/reader. `attempt` checks model and step identity before using saved role/call; sealed receipt prevents later saved-address traversal (`88-103`). | Model guard protects dead QObject, but raw step/reader are still retained across calls. Reset/reload must invalidate on identity mismatch before dereference; stale raw step comparison itself is not a dereference, but `s.step->db` is only safe while step storage is alive. | Opaque model generation + step lease/token that can be validated without dereferencing stale storage; test reset, reload, model death, and address reuse before attempting prefix. |
| Geometry prefix evidence tokens (`frame`, `object`, `registry`, `receiver`, `body`, `slot`; `geometry_temp_prefix.cpp:98-103`). | Stored as integer tokens after evidence validation and report sealing. | Receipt identity only; must never become a later dereference capability. | Preserve as diagnostic values only; test report remains readable after model death and no retry follows sealed receipt. |
| Scene named/main/second models (`scene.cpp:25-49`, `53-85`). | Named and second are stored through `DisplayModels` ownership/guards; second owned model replacement/deletion has explicit checks. | `displayNamedModel` returns a raw pointer to caller; its validity is scoped to display collection lifetime and can be invalidated by display teardown. | Return opaque model handle or scoped borrow; test named lookup across display teardown and second replacement/drop. |
| Slice collection (`doe_slice.hpp:80-88`). | Stores optional raw `GuiModel*`, raw `View` identity, and raw bound object. The slice cleanup callback is explicitly deferred until native object/list effects (`doe_slice.hpp:100-104`). | Raw model/view/object persist in collection state; model death/reset and view/object replacement require invalidation. Callback may resolve settings late, but captures/inputs must not preserve stale addresses. | Collection should hold opaque model/view/object identities and resolve settings/object at callback time; tests should cover reset/reload, dead model, object replacement, callback ordering and no callback after invalid owner. |
| Slice-plane store records (`doe_slice.hpp:64-77`) | `records` retains raw record pointers while a weak heap binding prevents adapter lease from reviving an ended process. | Pointer vector is valid only while heap owner remains alive; consumers must reject expired heap before touching records. | Opaque record IDs resolved through live heap; tests after heap expiry and session teardown. |

## Review boundary

The guarded model identity is useful but does not close aliases to step data, scene models, slice collections, plane records, or callback captures. In particular, replacing `GuiModel*` with a guard alone would leave the child-pointer and collection-lifetime cases above unchanged. The inventory is limited to the named paths and does not assert completeness for other converter code.
