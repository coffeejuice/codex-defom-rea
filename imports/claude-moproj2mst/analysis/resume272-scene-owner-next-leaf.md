# CP272 scene/view owner next leaf: skip Slice adaptation for a non-3D owner

A new finite actual-caller leaf exists in `viewer.cpp::bind`: an existing Slice collection does not by itself justify refusing object rebind. The retained original adaptation helper first resolves the View's actual model owner and tests that model for 3D. A live 2D owner returns without touching the collection. Current converter code refuses every nonnull collection, including the already-supported 2D/no-database fixture in `test_viewer_slice.cpp`.

This is independent of completed CP250 dimension copying, CP252 secondary default dimension, CP254 early secondary publication, and CP262 camera/radius work. It does not reopen named-map no-step failure behavior.

No new public seam, cache, synthetic owner, callback, or retained borrow is needed.
