The initial render builder `0x14126a190` receives secondary=curve+0x130 and returns without mutation or callback when signed vertex count N at secondary+0x58 is zero. Its admission is N!=0, not N>0. It owns an existing double-vector at secondary+0x60, writes stride 4 and segment count N−1, builds four indices per segment at +0x70, and resizes a distinct render vector at +0x78 to 6*N 32-bit words. For each of 2*N rows it writes original or displaced XY into slots `3*i+1/+2`, then calls `0x14126a620(curve)` to fill color slots `3*i`. Source reads may detach their double-vector. Index/render resizes preserve an existing prefix and can leave ordered partial effects. The builder frees two raw scratch arrays only after callback return and has no local rollback.

The decisive unresolved transform is `0x1417d0850(N,originalXY,double(widthFloat),displacedXY,true)` at `0x14126a319`. It can return −1 for N<=0, too-small absolute width or null arrays without initializing displacedXY, but the builder **ignores EAX** and consumes that scratch. Replacing it with duplicated vertices, zero-initializing rejected output or early-returning would change native behavior. Its full numerical, allocation and failure contract plus live width/color state remain unqualified. A finite parameterized packing suffix can be reconstructed with explicitly supplied original/displaced arrays and color words, but it is not complete public initial-bind fidelity; current converter curve items do not represent the separate index/render vectors.
