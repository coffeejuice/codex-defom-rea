# CP87 public-path decision: deferred, no source edits

No source-qualified public behavioral advance was found beyond the current
selected editor's private-palette guard. A canonical module-symbol registration
would be a public owner/registry join, but would pass no native guard and record
no new original effect. Root explicitly requested deferral in that case. CP87
is therefore released without source or test edits for the grouped build.

Only this report was written. No build/test execution, GUI/original execution
or mutable REA occurred. CP86 source remains frozen.

## Actual public path and existing coverage

`loader_l3.cpp::formingSimControl300Open()` obtains the real selected model and
main-window Session, calls `ConversionSession::beginEditor300Factory()`, then
retains `not_ported(0x6504abb0)`. The Session checks actual Project/Operation/
GuiModel/current-model ownership, creates one StagedEditor300, binds it to its
actual WidgetRuntimeState, and calls `continueNativeBase()`.

That base retains allocation/QObjectPrivate/QWidgetPrivate prefix effects, then
stops at `PrivatePaletteUnavailable`. No selected palette/font, native thread
retain, widget registration/count, UI setup or CG/page fill is fabricated.
`beginEditor300Factory()` explicitly expects this current issue. Loader's
later isolated legacy CG path is not the real bound Session route.

This boundary already has strong tests. In `test_conversion_session.cpp`,
`session_forming_factory_retains_actual_parentless_owner_before_ui_setup_guard`
drives the real objectTreeFill route, checks the exact factory/model/runtime
identity and palette stage, no setup/pages/thread/palette/font/registration,
unchanged later CG fields, and no replacement/replay on retry. Its companion
test checks invalid/unselected/substituted ownership before allocation.
`test_simcontrol300.cpp` also checks public convert returns Unsupported at
6504abb0 with empty MST/side outputs. Adding another same-boundary test would
duplicate these checks rather than advance recovery.

## Symbol-only cut considered and deferred

The actual Session startup already interns a probe003-derived application
palette/default/class-cache graph. This does not establish its module slot as
the current post-Open editor palette. The existing runtime API can separately
register the canonical QtGui+9c9690 SYMBOL with all slot/value optionals Unknown.

The considered two-file cut was `conversion_session.cpp` plus
`test_conversion_session.cpp`: at first genuine editor entry, register that
symbol on the actual Session runtime with the pinned module hash, without
setting slot presence, wrapper/data, value word or native count. It would not
call a getter, create a reference token, store a private data pointer, or alter
the palette refusal. Thus it is a diagnostic architecture join with zero new
native/public behavior. It is not selected for implementation. No exclusive
source set is being held and no CMake/shared header change is requested.

## Smallest missing prerequisite for a real continuation

The selected editor's current application palette source must be joined to
the same actual runtime/module, receiver/call frame and interned data at the
QPalette getter/copy boundary. Startup slot/data identity or a later widget
palette cannot be substituted. A qualified actual current getter result could
permit retaining its ONE native getter token and first private data-pointer
store, still guarding temporary deref while the current atomic word is unknown.
That would be a real bounded prefix, unlike symbol registration alone.

The still smaller witness covering both pointer and count is the same actual
selected private frame/data observed immediately before `6504abce`, with the
getter's +1 already included in its current mutation sequence. CP82 describes
the exact witness. Initial data-count1 and later splitter003 counts166/167/165
are not that state and cannot seed it. Even after this palette prefix, font,
later QWidget history and the separately captured startup174/editor760 phases
must retain their own guards; no count bridge is implied.

Once that producer is qualified, a future source lane would need the real
EditorBase getter/copy cursor and its focused tests, coordinated with the
existing runtime palette owner/reference primitive. It must not assign a
completed default palette directly to bypass the source retain/deref order.
No current observation closes that producer, and this report does not request
or start a GUI/native capture.
