## Guard, ordering and borrow audit

`withOwnerSimCtl` requires a callable taking `Cls_1401e7b10*` and yielding exactly `void`. It invokes the callback once with null when owner or project is missing, without looking up a model. Otherwise it calls `engine::opModel` once, then synchronously invokes the callback with `m ? m->simCtl() : nullptr`. Crucially, `m->simCtl()` is still evaluated before the callback and retains `GuiModel::requireGeometrySyncAvailable()` refusal. The helper does not queue or store the callable. The four call-site lambdas only conditionally write a control word; none stores or returns the pointer through a capture. The void result rule prevents return through this helper but does not, by itself, prove a whole-program lifetime contract.

`setMode` still runs optional engine defaults, stores `flag = pv::toBool(v)`, attempts its control word write, and only then calls `ht::propsRefresh(ownerProject(hp), hp)`. The later owner validation and refresh, including their own lookup and possible effects, remain at their old point. “One lookup” therefore describes this helper invocation, not the entire setter. `getMode` still writes before returning `pv::vBool(flag)`. `STEPDEF` `applyValue` stores converted `b.stpdef` before acquiring control and retains zero -> 1 / nonzero -> 3; `getValue` writes that mapping before assigning `out`. Missing control skips only the word write. No property-block creation, new null fallback, `withOpStep` substitution, or cache1 code appears in the cut. Internal C++ helper source access changed; the converter C ABI and model storage did not.

## Fixture and limits

The new `heattreat_property_simcontrol_writes_and_null_step` uses the existing copied-corpus HeatTreat reclassification, checks its real owner, model, block and loaded step, then exercises Deformation setter/getter and both STEPDEF mappings. It deliberately changes the Mode block flag before `getValue`, so the getter's control write is observable. It likewise changes STEPDEF from the prior setter result before the getter. In the null-step interval it moves the actual model step into `savedStep`, calls a Mode getter and STEPDEF setter/getter, verifies returned/block values and untouched saved control sentinels, then restores the step on both normal and exception paths. Testkit `REQUIRE` throws `Abort` on failure, so the catch restores it for that path too. Existing HeatTreat and CP176 Distortion tests remain. This is an internal synthetic null-step test, not a public Open or original occurrence.

The fixture directly checks Deformation (`0x108`) and STEPDEF (`0x1c8`); Diffusion (`0x110`) and PhaseTransformation (`0x10c`) use the same Mode helper by source inspection. The null-step fixture does not park a geometry barrier; retention of `m->simCtl()` establishes that guard path statically, and the existing geometry/Stopping suites supply regression coverage. Source inspection found no raw alias escape in this four-callback seam, but `GuiModel::step`, `GuiModel::simCtl()`, engine `opSimCtl`, L6 `simCtl`, and many other direct model accesses remain open. This cut does not permit Stopping cache1.
