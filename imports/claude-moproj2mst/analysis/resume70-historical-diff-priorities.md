## Priority

For an original comparison, A55 remains highest information value **only after** the independently verified app-control release gate is satisfied. It is the only case with a narrow raw delta whose candidate source-qualified explanation is a specific callback, and the fresh capture can distinguish a mode/input mismatch from a missing lifecycle prefix. That gate remains closed; this report does not schedule GUI activity.

For candidate-only engineering, the highest-value next bounded investigation is the Type=2 DOE activation boundary on a synthetic post-action-state input, starting with B121's nonempty TLOC mapping. B120 and B122 then share its study-owner prerequisite and can be layered without treating their historical before/after folders as valid equality oracles. B98 already has a narrowly scoped candidate test and does not justify another comparator adjustment. A55 mode-only candidate runs would establish adapter behavior but cannot produce a mode-1 public Save tree while the `0x6504abb0` setup guard remains.
