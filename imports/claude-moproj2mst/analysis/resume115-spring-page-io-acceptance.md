## Source-backed fixture and exact bytes

Each case creates a unique ordinary non-reparse short child of existing C:/PROBLEM, checks every possible sidecar path is shorter than100 characters before creation, and owns one native IO instance. Input is the exact valid ASCII one-row profile with absent SPRING2.INI:

```text
1\r\n10\r\n0.5\r\n1.5\r\n20\r\n0\r\n1\r\n0\r\n
```

This notation denotes30 raw bytes, SHA-256 `7d43e860ac36a5310cc945e938e5d8c56feaf36d90e7df8b12bceebd56616058`. Test-qualified first/second combo item-data lists are `{0,10}` and `{0,20}`; they prove membership for this bounded page input, not that a native widget populated those entries. Original140ec8b00 uses its own object predicate before combo insertion; no candidate model objects or observed native eligibility are fabricated here.

The independently reconciled writer list is `[count,LF,firstObject,LF,firstValue,secondValue,secondObject,direction0,LF,direction1,direction2,LF]`. Every non-LF item gets a TAB; the binary stream gets finalCRLF. Thus exact output is:

```text
1\t\n10\t\n0.5\t1.5\t20\t0\t\n1\t0\t\n\r\n
```

This denotes28 bytes, SHA-256 `981c3323ad2fa966f97159a51253075e583d111cdecf108c0d4a698757fbddb6`. An earlier independent proposed byte string omitted numeric tabs and moved field breaks. Before fixing the assertion, this lane compared the retained1410db030/1410da9e0 bodies and directly read the original four LF literals; oracle and root independently confirmed the corrected string above. No expected bytes are generated by calling the candidate writer itself.

## Three focused cases

1. Seed the row and no companion; read through native IO, assert exactly one record and all seven fields/zero flag; Fill through root's two-combo-ID overload; assert selected row0, both IDs, page checkbox, five visible numeric texts and flag checkbox. Apply the no-edit page after the existing constructor text refresh; preserve actual output bytes before comparing them to the literal, require absent companion, then reread/reapply the normalized one-record output and require stable bytes. This depends on the reader lane admitting the same valid fields separated by the writer's canonical whitespace, rather than only one historical byte spelling.
2. Open with companion absent and flag0, then create a readable companion only after Fill. Apply writes the same primary and removes the late companion. The raw late companion is retained before deletion. This is the source-qualified Save-time deletion branch; it does not admit a present-companion reader or change the stored flag.
3. Keep explicit guards for the old no-combo overload, missing first ID, unknown locale, changed visible value, present companion at Open and count2. These profiles must refuse without overwriting the seeded bytes. Present-companion and count2 reader refusals require Unsupported, preserving their own input bytes. No user-edit/multi-row/fallback behavior is claimed recovered.

All successful page paths require zero NBC warnings. No unrelated sidecars are seeded. The fixture preserves input/expected/actual-first/actual-second bytes and scope/path/cleanup records under the CTest-configured checkout M2M_TEST_SCRATCH. C:/PROBLEM cleanup resets the IO owner, checks canonical leaf/direct parent/reparse state, deletes only the two known spring files and removes only the empty owned leaf. It never recursively deletes or falls back to another project location; unexpected files retain the leaf and fail cleanup. An unavailable/unwritable C:/PROBLEM must remain a real test failure.
