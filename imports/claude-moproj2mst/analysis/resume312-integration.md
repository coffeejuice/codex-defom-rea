# CP312 inert worker and fake topology rehearsal

The v2 worker input carries only a CHILD job handle. The supervisor must remain the sole owner of the WORKER job lifetime handle so its death can close that job. Before creation, the worker checks the CHILD job's kill-on-close limit and rejects silent breakaway. It records raw creation and CHILD membership telemetry, then waits for a nonce/handle ACK. The supervisor must independently check WORKER/ancestor limits, exact worker/child membership, image identity and cleanup before any live test.
