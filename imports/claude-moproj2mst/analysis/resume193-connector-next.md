## Identity, ordering, and partial state

Qualified RAX is the private-allocation identity; qualified RBX is the pending public Report task identity. The destination is therefore private allocation `+0x08`, and its new value is the public task token. Keep this direction separate from CP190 public task `+0x08`, whose value is the private token. R12 copied the private token at CP191; CP192 spilled the same private token at `[RSP+0x58] = [S+0x60]`, where S is initializer-entry RSP and live RSP remains `S+8`.

The local order is public task+8 publication at `0x131425`, R12 copy at `0x131429`, caller spill at `0x13142c`, reverse private+8 publication at `0x131431`, then TEST RDI at `0x131435`. CP193 supplies only the reverse store. Do not combine it with the preceding spill or the following TEST.

Before the cut, current private+8 is the qualified zero retained from the initializer and `privateTaskBacklinkAvailable` is false. After the cut, current private+8 holds the qualified task token and the reverse-publication marker is true. Represent this with a tagged zero/task-token slot, or an explicit qualified transition with mutually exclusive current states. The existing `optional<uint64_t>` zero observation must not be used to encode a host pointer or remain asserted as the current value alongside publication. Historical zero initialization can remain provenance, clearly separated from the current slot value. A boolean alone does not establish the stored identity.

Add an explicit successor phase such as `BeforeCallerParentTest`, deriving cursor `0x131435`. After all admission succeeds, commit current slot value, reverse-publication marker and phase with nonthrowing operations; do not expose a partially changed model on refusal. This is a modeled transition, not a claim that native fault or concurrent visibility is transactional.

Preserve public task+8 value/marker, R12, CP192 spill, every other represented register and stack slot, saved RBX `[S+0x10]`, saved RDI `[S-8]`, return slot `[S]`, CALL/RET lineage, initializer provenance, shared-null ownership and references, other sparse private fields, and allocation/reference counts. MOV changes no arithmetic flags; the retained XOR flags remain current because TEST RDI has not executed. `complete` and `qobjectBaseCompleted` remain false. A pair of published links does not complete QObject initialization.

## Admission and phase guards

Retain the complete CP192 prefix: pending Report ordinal and allocation sizes; original QtCore digest; public/private tokens and address-point bindings; live allocation owner checked by both stored pointer and shared ownership control block; matching live widget/shared-null roots, pointees, ownership and committed references; sparse fields and flags-expression provenance; initializer version; RAX private, restored RBX task, restored RDI, R12 private, zero RSI and XOR flags; RSP `S+8`; saved slots and CALL/RET lineage; exact task+8 publication value/marker; and the allocation-bound caller spill's private token, owner, ordinal, module, instruction `0x13142c` and both stack offsets. Missing, expired, foreign or inconsistent state refuses before mutation.

Qualify the new stored task token and destination against the same Report allocation pair, live owners/control blocks, ordinal, module, instruction `0x131431` and destination offset `+0x08`. Do not accept another Report task, a private token in place of the task token, or an equal-looking host address with foreign ownership. Pointer identity and control-block identity are distinct checks where ownership is represented.

Extend both early and complete prefix guards. Before CP193 the reverse observation/marker must be absent and the phase-appropriate private+8 zero must remain intact; at CP193 require the exact task token and marker, and reject a simultaneous current-zero assertion. Existing zero-prefix admission must recognize the transition only at the new successor. Public publication, R12, spill, restored-register and cursor guards must admit the new phase while preserving their earlier phase restrictions. Completion flags remain forbidden.

Terminal reentry must validate the complete successor state even under a smaller admitted diagnostic budget, then stop at `0x131435` without replay. A deliberate rewind to CP192 must restore the current private+8 zero, clear the reverse token/marker and restore phase/cursor together while retaining CP192's spill. A phase-only rewind must refuse. Preserve all historical budgets and task-key behavior; extend the absolute maximum/default only for this one separately admitted instruction.
