## Implemented boundary

`StagedEditor300::environmentCurveClicked(binding,curveIndex,selection)` admits curve indices0..2 and choice0/1, same live Project/OPI-generation/GuiModel/remesh binding, completed private page metadata, and matching source-model/remesh tokens. It assigns only the selected `EnvironmentCurveControls` tuple:

`{constantChecked=constant, tableChecked=!constant, constantInputEnabled=constant, constantUnitEnabled=constant, definitionEnabled=!constant}` with constant=choice0.

There is no pageState/simCtl query, sourceControl dereference, curve owner/payload inspection, currentCurveIndex assignment, numeric read/refresh, allocation/free, OPI/model/remesh mutation or I/O. The method can therefore complete for retained controls after the same live model's actual step becomes absent/replaced, matching the absence of an SC prerequisite in these three bodies. This differs deliberately from reactionRateClicked's later model stores.

Choosing constant does not immediately clear a temporary dimension or free a table. Choosing table does not discard invalid cached constant text. Later applyEnvironment3D retains its existing source-backed validation, temporary mutation and model copy order. Other unsupported Apply profiles remain guarded; no new physical-enabled-input validation is invented.

Invalid index/choice, wrong identity, partial/native-base-pending owner or expired OPI generation refuses before projection. These owner/range admissions are private candidate prerequisites. Public mode300 palette/6504abb0 and completeForPublicSave=false remain unchanged. No lifecycle or CMake path was enabled.
