## Decision

**Accept the source cut; block full CP169 test acceptance on the incomplete prewrite refusal matrix.** The inspected source models private `+0x50` as initially unknown, validates the accepted CP168 frame before writing, sets only that field to zero, and stops at the independent `+0x58` instruction at RVA `0x1311c3`. The focused test covers the ordinary first call, reentry, actual `ConversionSession` pairing, and three malformed predecessor fields. It does not cover several CP169-specific refusal cases required by `resume169-connector-next.md` and its plan review. This is a test evidence gap, not an observed source defect.

Their validation precedes mutation. `:254-280` checks the retained Report and private pointer, `0xc0`/`0x88` sizes, written `0x23cac8`/`0x1a9d10` address points, both root bindings, hash/RVAs and commit markers, zero `private40`/`private48`, unknown `private50`, and incomplete/backlink state. `ownsWidgetRuntime` at `task_runtime.cpp:30-37` checks both shared control-block and pointee identity. - `task_factory.cpp:282-300` throws at `RVA 0x1311c3` before any `+0x58`, QVector, second QList, backlink, completion, or cache step. Native profile initialization precedes key lookup, so same-key and different-key reentry reach that stop without repeating the earlier stores or reference commits.
