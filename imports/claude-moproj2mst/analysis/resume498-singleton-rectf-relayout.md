The original editor computes the selected singleton cell from RectF top-left, then moves the model rectangle to that grid origin. The public parser now reproduces that move for one initially empty, unlinked ordinary `SfOprForming2D` with missing/full-sentinel CellPos, finite original `(x,y,0,0)`, `x<1332.5` and `y<67.5`. The resulting cell is row0/column c and RectF `(205*c,0,0,0)`; links stay null. The PE and Qt `QRectF::moveTo` evidence is in `analysis/cp498-singleton-rectf-relayout-source-contract.md`. This is static selected parser/model recovery, not fresh original runtime parity.
