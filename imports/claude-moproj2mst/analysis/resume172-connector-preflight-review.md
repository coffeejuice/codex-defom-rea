It has no QVector record or private `+0x68` binding. The isolated brush-gradient helper does not establish this root's pointer identity or shared process interning.

The plan's request to inject a missing, wrong, or malformed *root* QVector record is not reachable through the proposed public model if `WidgetRuntimeState` privately constructs one stable record and exposes only a const getter. Its module hash and RVA are `static constexpr`; they cannot be changed through `const_pointer_cast`. Test a wrong or premature **private binding** and false/true reference marker at the `BeforeQVectorSharedNull` seam, then rely on the root's construction and static qualification for the record itself. A foreign or aliasing-foreign factory root cannot reach this retained seam through the public API: a new factory allocates a new Report and the first QList guard rejects the wrong owner. Existing earlier-root tests plus same-frame root expiration are the reachable owner cases.
