## Decision

I found no new source-closed **public Open→Save** operation/property branch outside the existing Type3 optimizer and FRCROT owner/parser guards. The settled dispatch inventory remains: base active-operation Save and the admitted property writers are implemented; Convert2Dto3D's Open-time property application is already wired; CopyMirror's writer-local `vt+0x60` prefix is repaired but CopyMirror is not registered publicly; DoeOutput/Report require unresolved native owners; Distortion's `vt+0x198` body is not retained. No generic dispatcher change is justified.

The closest current partial caller is DoeOutput active Save. CP149 already integrated its first immediate `Control/Regions` directory attempt and actual current-operation model lookup. Thus DoeOutput cannot presently serve as a public Open→Save regression even if the private cleanup device were completed.
