# CP254 secondary publication-order contract independent review

## Verdict: PASS within the canonical empty-secondary scope

The retained original `0x140cf9990` order is accurately represented: after successful allocation/construction, it publishes the secondary through `0x140cbc920` before setting the secondary's display backlink and before either control query. The source repair's proposed early `displaySetSecond` handoff places publication at that boundary, then obtains the model through the display guard, sets the backlink, queries new control before main control, and conditionally copies GEOTYP. The original control getter is nullable; the converter's later main `simCtl()` can throw its reconstructed geometry barrier after publication.

The exception-prefix reasoning is sound for the stated canonical state. Before handoff, the local `unique_ptr` owns the complete newly constructed model. `displaySetSecond` sets the guard and transfers the unique owner; with an empty guard/owner and no callback, successful transfer leaves the display owning the published model. The backlink store follows, then a parked main can throw during `b->simCtl()`. Unwinding the local raw pointer does not destroy the secondary, so the display retains the partial prefix until explicit `displayDropSecond` or display teardown. Constructor failure remains pre-publication. No rollback is proposed or inferred.

The contract correctly restricts the claim to a valid synchronous empty-secondary path. It identifies the public-state caveats: a null guard with stale `secondOwned`, cross-aliasing that owner as main, and external/reentrant mutation can make early owner replacement destructive or invalidate cached `b`. It does not claim native parity for the converter's foreign-owner refusal or for those inconsistent states. It also separates the original raw nullable getter from the converter's geometry guard and describes a parked-main test as converter evidence only.

The proposed test setup uses the existing parked geometry fixture and actual `displaySecond` caller. It requires an initially empty secondary, seeds main GEOTYP before parking, verifies the exception plus published guard/owner/backlink and unchanged default GEOTYP, then checks repeated-call identity and explicit drop/guard expiry. Placing the construction case after existing pure-refusal global snapshots avoids treating new-model constructor initialization as a side effect of the earlier rejected query. A separate ordinary caller assertion covers successful GEOTYP copying. The plan warns against guessing the new control default and against using snapshots to erase constructor/global effects.

The report qualifies the static function ordering and does not claim observed original allocation, constructor, Qt guard, SEH, or exception behavior. No source, tests, build, GUI, or mutable REA state was changed or run for this review.
