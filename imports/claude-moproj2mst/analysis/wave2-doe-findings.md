## Recovered sample contract and isolated implementation

Constructor `0x140919b80` sets current mode0, requested count for mode0 to100, three empty sample tables and three invalid flags true. It does not explicitly initialize mode1/2 count fields. New `SampleState` keeps those unknown with optional values. The rest of the base/derived manager lifecycle is not claimed complete.

**Correction to the preliminary inference:** `0x140917630` appends one row vector, retaining order and duplicates. The apparent repetition count in the writer is Qt's foreach loop-control counter (`0x140dfc080`), not sample grouping. `0x14091d110` ensures/resizes/generates the current design and returns a table copy; duplicate grouping was not established. Legacy `designCounts` is still an explicit caller-supplied run-count seam, not populated by the new state.

* `0x140915360` writes mode plus newline; then each row as sequential one-based id, tab, every double (QTextStream defaults, SmartNotation/precision6) followed by tab, then newline. QFile WriteOnly|Text means Windows CRLF. Empty vectors produce `1\t\r\n`. Input rows are not consumed. Open failure returns false; after close the shown body returns true without checking stream status.
* `0x1409157c0` clears rows before open. After successful open, first-line token0 replaces mode using QString::toInt (failure→0); empty/whitespace header leaves it unchanged. Later lines split QRegExp `\\s+`, SkipEmptyParts. Only lines with more than one token append rows, ignoring token0 and converting the remaining tokens through QString::toDouble (failure→0). Widths need not agree and row identifiers need not be numeric. Low-level parser does not validate mode.
* `0x1400d75a0` saves valid current samples to `<DoeStudies>/<name>/Control/DEF_DOE.PAR`; `0x1400d7790` saves a valid specified table to the supplied path. Invalid flags suppress these writes; specified modes outside0..2 return false.
* **Load bug**, `0x1400d7a80`: for mode0..2, constructs an EMPTY table then calls writer `0x140915360`, overwriting the Samples file with only its mode header. On writer success, if the requested stored table is nonempty, it empties the **current-mode** table and clears the **requested-mode** invalid flag. It does not read the file. Empty requested tables leave flags unchanged.
* `0x1400d7820` reads DEF_DOE.PAR into a local table and directly into manager mode. On successful read it assigns that table, clears its invalid flag and sets its row count. The new decoded-text commit helper refuses out-of-range modes after retaining the mode parse effect; original unsafe indexing has no fabricated success/crash contract.

The isolated parser accepts **already-decoded QTextStream text**. Raw file decoding, BOM/codecs, open/read/write failures, dialogs and their state ordering remain unfinished. FileEffects helpers plan successful-open effects in the existing source style. In particular, `loadSampleTable` queues its write before changing memory; the original skips memory changes if the actual QFile open fails. It is unsafe to wire this helper until the caller can honor the real I/O result before committing state. This is not a filesystem failure-path implementation.

Seven focused tests cover defaults/unknown counts, the recovered whitespace set (the initial U+0085 refusal was later removed), ASCII numeric failure, duplicate order, formatting, writer gates/path, load bugs and unsafe-index refusal. The historical120 test supplies100 empty rows explicitly, confirms preserved UI-created bytes, then confirms the parser drops all100 on reload. This is neither default sampler reconstruction nor fresh-original acceptance. Original Qt QString::toDouble first tries default QLocale, then C locale; the reused numeric seam is C-only. Full locale/edge equivalence is not established. The shipped regex routing is now closed by `wave2-doe-regexp-space-contract.json`: U+0085 is a nonseparator and stays inside its token; the candidate refusal was removed.
