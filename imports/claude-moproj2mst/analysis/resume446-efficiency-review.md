# CP446 efficiency review

The CP443 plan change eliminated a redundant preliminary full build/launcher from the selected acceptance path. CP444 used focused preflight, one full build, one bound launcher and freeze. CP446 did the same after source repair: its selected builder took 94.377 seconds (configure 11.343, focused build 0.984, focused tests 0.719 and 0.782, full build 71.656), and the bound launcher took 62.360 seconds (fixture hashes 21.500 before and 12.172 after; CTest 21.515). Both runs were source/binary stable. CP444 builder and launcher were 56.043 and 50.297 seconds. The different source changes and build invalidation prevent interpreting their elapsed difference as an optimization regression or speedup. Token usage was unavailable.

CP446 had necessary diagnostic rework: a direct CMake command lacked the MSVC/SDK environment, then the configured focused builder compiled; the old L5 test rejected the newly evidenced positive-builder guard, so it was corrected; independent review then found a stale sidecar path, fixed before the selected acceptance run. For the next source increment, run independent semantic review as soon as the source diff is stable, use the configured builder for focused compilation, and do the grouped full build/one bound launcher only after behavioral repairs. Do not skip focused evidence or the source-stable freeze. The fixture-hash phases remained material, but no safe cache change has yet been measured across equivalent candidate runs; retain current binding.
