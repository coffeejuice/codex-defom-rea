# CP65 actual geometry element-owner admission

Geometry readiness now accepts an existing E owner only when it equals the view's
actual live model step. Native owner+1b59 returns true for both zero and nonzero
values, so this exact identity qualifies the already ported connectivity getter's
fast-return fold. The independent N-owner/nonzero-u1b58 rule and all CP64
Unqualified refusals remain in force.

both branches. Synchronization immediately returns via `14082efc4`, with no

`qualifiedGeometryReadiness` still rejects absent coordinates or a noncanonical
registry before getter effects. When either nested owner is nonnull, it resolves
the existing guarded view model once. Nonnull E owner must equal that model's
live step, compared as pointer identity; arbitrary E addresses are never read as
models. Existing N owner must independently equal that actual step and have
nonzero actual u1b58. Null N owner needs no node synchronization flag, even when
E is bound to the actual step. No source owner, flag, dimensions or arrays are
written to manufacture admission.

The existing port's E getter returns E+8 directly. This fold is now admitted only
for null or live actual E identity. Native's omitted read is of ordinary
nonvolatile actual-model storage and has no surviving state effect; the code
does not claim native never performs that byte read/call. Opaque identities,
concurrent lifetime changes or volatile/memory-mapped owner storage are outside
this contract. No shared model helper was changed.

Readiness still calls coordinates then connectivity; populated follows
count/count/width and the second getter round. Known null connectivity remains
Skip with edge-only bounds; Unqualified still marks the contribution unknown
before any builder arithmetic. All prior malformed builder guards remain.
