Cogging.MDT now has a per-operation native property writer. It checks the retained owner, opens the actual destination before serialization, and updates writer globals only after a successful open. Failed open returns the handled-class result so later property writers and MST generation can continue. The native path stages no replay; aggregate recording retains its existing bytes and explicit path refusals.

The shipped path is QString operator const char followed by static CRT fopen("wt"). The default null-CString-codec profile uses Latin1 bytes, with first-NUL termination. The static CRT uses _SH_DENYNO40 and CreateFileA with GENERIC_WRITE, share READ|WRITE, CREATE_ALWAYS, normal attributes and an inheritable handle. The implementation pins these Win32 parameters, then wraps the handle in a CRT text FILE with an explicit4KiB buffer.

The original normal buffer is4096 bytes. A failed CRT flush sets its error flag but discards the attempted buffer; later printf calls remain independent. The writer ignores every printf and fclose result. Seven focused tests cover direct sharing, failed-open global effects and continuation, owner/missing-parent/unencodable paths,4KiB boundary/CRLF/NUL conversion, failed-flush discard with later printing, and failed close. The coordinator owns builds and tests; the first test compile required adding the complete OpClass definition via writer.hpp. Source/tests are frozen after that include correction.

The [machine-readable receipt](wave3-cogging-native-io-contract.json) retains16 bounded original/Qt captures, exact addresses, source/evidence hashes and current validation state. This is the normal allocation regular-file/default-codec profile. Configured CStringcodec binding, the original two-byte allocation-failure fallback, descriptor/FILE exhaustion and old-CRT disk-full/partial-write byte accounting remain explicit limits. Host UCRT printf/text low-level writes are used with pinned buffering; complete old-static-CRT parity is not claimed. No original runtime or UI was used.
