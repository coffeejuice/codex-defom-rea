This receipt would support a narrow integrated constructor-stage gate/reset through the existing Project/Session notifier owner, stopping before key/list/receiver effects. Run it as a preflight on a future qualifying record, then independently verify original module/input/probe hashes, hook installation and coverage, all normal returns and read-error/overflow status.
