# CP453 private ShapeOptim prepared-value projection

CP453 implements the optimizer-present, normal-path prefix of original ShapeOptim consumer `0x14013d740` as a private seeded-state helper. The original instruction and value contract is in `analysis/cp452-shapeoptim-consumer-report.md`, bound to 2,586 matching bytes of the imported original PE. `Type3ShapeOptimPreparedState` names the selected original destination offsets; it does not claim the native class memory layout.

The helper reads CP451 prepared DefOptModel values, writes scalar destinations in original order, derives `+c4` with signed remainder, resets only flags `+98..+9b`, then traverses NUM_CON rows by parser tag at node `+4`. Special tags write their original shared fields and flags; `0x439` derives `+9e` from existing `+74`. Fallback rows append their int `+4` and double `+18` values in order. Region names append in order, including duplicates. Incoming lists and other destination fields remain seeded across calls. The helper ends after `+e0/+e9`; property traversal, logs, setter calls and final refresh are separate.

Independent source review found no functional blocker. Before the selected build, we moved the row-count read after the four flag resets to match native order and added a single-row `0x3f4` case that observes its shared writes without later overwrite. The focused suite covers signed and threshold arithmetic, scalar destinations, all row branches, tag versus classifier, clamps, the `0x439` dependency, double bits, retained fields, region ordering and repeated appends.
