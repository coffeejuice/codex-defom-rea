# CP62 test-run source and executable binding

Updated `admin/run_converter_tests.py` to record a test execution binding around CTest. Immediately before CTest, the receipt now captures a SHA-256 fingerprint of every file under `source/` and a size/SHA-256 manifest for every registered CTest command executable plus each `M2M_CLI` executable referenced by the inventory. It repeats the same capture immediately after CTest and records both snapshots under `execution_binding`, with `stable_during_test` indicating exact equality.

If the source fingerprint or any captured binary changes between the two boundaries, the receipt is marked `failed-or-incomplete` and the launcher returns nonzero. An end-of-test capture error (for example, a deleted or unreadable executable) is retained as an incomplete binding with a diagnostic. The raw CTest return remains available as `ctest_exit_code`; `exit_code` now reflects binding failure too, so existing freeze logic that requires `exit_code == 0` cannot accept a detected drift. Existing receipts remain readable because the change only adds fields. Existing CTest-only `elapsed_seconds` remains scoped to the CTest process; the added hash work is measured in separate `execution_binding_before` and `execution_binding_after` launcher phases.

Focused validation: `python -m unittest discover -s admin -p test_run_converter_tests.py -v` passed all 3 cases (stable snapshot, source edit detection, binary replacement detection). `python -m py_compile admin/run_converter_tests.py admin/test_run_converter_tests.py` also passed. No converter build or CTest run was performed.

The freeze checker should additionally require `execution_binding.stable_during_test == true`, compare `source_tree_before` to the build receipt’s source fingerprint and file count, and compare `binaries_before` with the build artifact hashes. Runner-side equality detects mutations during CTest; the explicit freeze comparisons establish that the stable tested snapshot is the one produced by the selected build. That checker change is outside this assignment and was not made.
