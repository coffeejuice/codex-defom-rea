## Implementation and guard

`frequencyIndexChanged(binding,row,selection)` requires same live Project/OPI generation/GuiModel/remesh, completed private page metadata/source-model/remesh tokens, row0..5, valid selection(row0:0..2;others:0..1), and cached frequencyCombo[row] equal to the delivered value. The caller's combo change precedes declared delivery and is not rolled back by refusal.

The method queries actual current SC, requires its original sourceControl identity, reads the live column stride and admits stride1 before any branch. It does not use pageState during early admission. The custom branch projects optional enabled=true and completes without consuming table row/component shape, values pointer, old model frequency or cached text. Store branches require the existing6-row/ncomp6/non-null values profile, write the exact double, then project enabled=false.

Missing/replaced SC, unrecovered stride or unsupported store table returns UnsupportedSnapshot before changing the previous enabled projection/model data. There is no later candidate guard after a completed model store. Exceptions from source lookup propagate before enablement. These owner/table guards are candidate admission, not native graceful-null/failure claims.

The enabled array is a private projection of the reached QWidget setter argument, not physical disabled-bit state or evidence of receiver/signals/reentrancy. Its initial Fill assignment is root-owned and corresponds to the explicit setEnabled following every native setCurrentIndex, independent of whether that index change emits. Unknown optional state is not invented as true/false. Text, numeric locale, validator state and same-index equality are not new handler predicates.

Automatic→custom enables remembered text while model frequency remains0/-1 until explicit frequencyTextEdited. No cache assignment, combo event or Save synthesizes that edit. Existing Fill/Apply numeric admissions, actual-widget/native constructor qualification and public palette/6504abb0/completeForPublicSave=false remain unchanged.
