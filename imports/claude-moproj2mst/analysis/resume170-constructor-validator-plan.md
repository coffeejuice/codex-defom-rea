## Smallest safe extraction

Extract only the common, read-only qualification used by the four zero-field branches in `source/apps/moproj2mst/src/doe/task_factory.cpp`: `BeforePrivateZeroFields` (current lines 205-231), `BeforePrivateZero48` (232-257), `BeforePrivateZero50` (258-285), and `BeforePrivateZero58` (286-314). Keep the earlier first QList, final private address-point, and QString admissions in place. They have distinct mutation and refusal order and would make this helper larger and harder to audit.

A file-local `qualifyRetainedZeroPrefix(...)` can accept the already locked `TaskAllocationStore`, its pending Report ordinal and pointer, the retained `QObjectPrefix`, and the factory's locked `WidgetRuntimeState`. It returns `std::optional<QualifiedZeroPrefix>` containing strong references to that exact root and its qualified QList/QString shared-null records, plus the retained private pointee. Returning a value only records qualification; the helper performs no allocation-store, frame, root-delta, map, or phase write. `shared_ptr` copies/weak locks and the existing `string_view` symbol checks suffice; it needs no new public header, state field, register emulator, or absolute Qt reference count.

The helper must check, before returning a snapshot: the live root belongs to the store through `ownsWidgetRuntime` (both control-block and pointee identity); the ordinal resolves to this same pending Report; Report kind and `0xc0` size; a live `0x88` private object whose pointer equals `allocatedPrivateIdentity`; written task/private address points at `0x23cac8`/`0x1a9d10`; both committed shared-null markers; nonexpired bindings pointer-identical to this root's QList/QString symbols; the qualified module hash and symbol RVAs `0x2f0a50`/`0x2f0b30`; and false base/frame completion and both unavailable backlinks. These are the common immutable facts repeated in all four zero guards. Do not test whether a root delta equals one: independent frames legitimately accumulate deltas on the same root.

Each existing phase branch remains explicit and retains its current `M2M_E_UNSUPPORTED` message. After successful common qualification, its local prewrite check must still state the exact predecessor field observations and later sparse unknowns:

| Branch | Exact local field condition before writing | Only admitted write and next phase | Existing refusal diagnostic |
|---|---|---|---|
| `BeforePrivateZeroFields` | `private40`, `private48`, `private50`, `private58` all disengaged | `private40 = 0`; `BeforePrivateZero48` | `private+0x40 zero requires committed matching CP166 roots at RVA 0x1311b5` |
| `BeforePrivateZero48` | `private40 == 0`; `private48`, `private50`, `private58` disengaged | `private48 = 0`; `BeforePrivateZero50` | `private+0x48 zero requires committed matching CP167 roots and private+0x40 at RVA 0x1311bb` |
| `BeforePrivateZero50` | `private40 == private48 == 0`; `private50`, `private58` disengaged | `private50 = 0`; `BeforePrivateZero58` | `private+0x50 zero requires committed matching CP168 state at RVA 0x1311bf` |
| `BeforePrivateZero58` | `private40 == private48 == private50 == 0`; `private58` disengaged | `private58 = 0`; `BeforeQVectorSharedNull` | `private+0x58 zero requires committed matching CP169 state at RVA 0x1311c3` |

Use one helper call in each branch, followed by its local condition, throw, single field write, and phase advance. Do not loop across phases or combine the writes into an atomic transaction: the first call currently accumulates native-order partial effects, and a later malformed checkpoint must retain earlier committed observations. The phase-specific diagnostic must still identify the failing cut; the common helper must return an unsuccessful qualification instead of throwing a new generic message. Keep the final RVA `0x1311c7` stop and the earlier fallback diagnostics. A qualified snapshot must not license a later phase or cache operation.

## Measurable reduction, risk, and rollback

The four current guards repeat 27 identifiable common predicates each: root and store identity; Report ordinal/pointer/kind/size; private existence/identity/size/address; task address; two binding/commit/hash/RVA groups; and four completion/backlink flags. One common definition plus four calls would remove 81 repeated predicate occurrences from the *source review surface* (`27 × (4 - 1)`), while retaining all four phase-specific field predicates and diagnostics. This count is a static duplication estimate to confirm from the actual diff, not elapsed-time or token savings. Record old/new guard line counts, focused failure/repair cycles, and equivalent build/launcher receipts before making any efficiency claim. CP167-169 build/full-suite times in `analysis/resume169-efficiency-review.md` are stable but do not measure reviewer time; no speedup factor is supported.

The main risk is accidentally broadening a phase by moving its sparse-field condition into a generic validator, or changing an earlier observable effect while chasing a later refusal. Reject the extraction if the diff cannot keep each phase's local condition and message legible, if a qualified-clone/foreign-root case changes outcome, or if the focused and source-stable gates regress. Roll back the one file-local helper and four call sites to the frozen pre-extraction source, keep any independently valid CP170 test correction, and rerun the same focused gate. No public API or persisted state migration is involved.
