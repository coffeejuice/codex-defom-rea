# CP164 RINHERIT independent review: SessionRoot publication

## Decision

`D+0x30` publication is **not source-ready in the actual Report owner/context**. The bounded original instructions establish a conditional local sequence: the lazy accessor constructs `SfInteractivePost` from current `D+0x48`, stores it at `D+0x30`, then invokes a helper that creates a `SessionRoot` element and calls `appendChild` on a copy of current `D+0x58`. This supports an isolated, guarded call-sequence contract. It does not establish that the selected Report Open/Save/accepted-Close occurrence invoked that accessor on its live document, that the Qt append succeeded, or which current payload and DOM values Close must release.

The CP164 report's detailed wording already qualifies allocation, Qt behavior, mutable state and owner identity. Its opening sentence, “which is appended,” should be read as **an append call attempted along the successful construction path**, not an observed successful DOM mutation. The returned `appendChild` result and QtXml internal effects are not closed by the selected PE bytes. This distinction matters because `D+0x30` is stored before the DOM helper call; a failed or interrupted attachment cannot be silently normalized into an atomic publish-and-append operation.

## Evidence and the missing dependency

The source-bound local sequence is strong: CP161 covers complete `0x140645320` and `0x14065b260`; CP164 covers complete `0x1406453c0` and `0x14065b470`, including the `SessionRoot` literal, QtXml `createElement`, and `appendChild` call. Those are immutable original `DEF_GUI_MO_64.exe` v11.0.2 bytes, SHA-256 `fd8ae1f8dd50d068267b3b7e49efdf11eaa178889131e59ec4b6f8de64725acc`. The report's half-open range hashes qualify the selected instructions. No original same-instance runtime outcome is supplied.

The exact dependency is **current Report document identity and state at the admitted call**. CP145 binds the Report Save callback to a fresh active-SubProject lookup and `0x1400b5ad0(S)`, then `0x140645030(D,path,1)`, before the viewer callback. CP161 binds Report's model call to another current `0x1400b5ad0(S)` return. These separate lookups do not alone prove one persistent `S` and `D`. A fresh document has `D+0x68=1` and constructor argument `D+0x2a=0`; CP164 shows the earlier Save route through `0x14064a830 -> 0x140646550 -> 0x140645320` requires `D+0x68!=1`, while CP161's later direct Save call requires current `D+0x2a!=0`. Neither constructor default determines the values after intervening callbacks, writes or rebinding. The selected `0x14064ab80` default branch is only a prefix, and its indirect effects are open. The unrelated `0x14064e220 -> 0x14064ed40 -> 0x1406459d0` lazy-call chain lacks an active-Report-D binding.

CP160 establishes the conditional accepted-Close deletion chain, but its fresh `SUB+0x30` reads, the actual QObject parent, and D's current `+0x20/+0x30/+0x40/+0x48` remain occurrence-dependent. The candidate reflects this: `src/engine/report_document_slot.cpp` records only an explicitly qualified opaque slot identity and stops before the deleting virtual; `src/engine/save_current.cpp` still refuses Report Save. The DOE `SessionDocument` in `include/m2m/doe_session.hpp` is a Type2 study projection and does not supply Report's `SfInteractivePost`, QObject owner, or QtXml append result. These existing seams cannot be promoted to a source-owned Report document by adding a `SessionRoot` node alone.

## Bounded next evidence

1. Finish complete `0x14064ab80` and the Report Save caller's intervening `D+0x68` writers/rebinds. Record its indirect call targets/returns only as far as needed to decide whether the default `+0x68=1` branch can invoke or alter `D+0x30`. Keep the `+0x2a` branch separate. A direct-reference scan is insufficient to exclude callback-driven calls.
2. If static closure cannot bind mutable values, obtain one **same-instance** original occurrence only after the supported GUI-control release gate is satisfied. Bind selected Project P, active SubProject S, `0x1400b5ad0(S)` return D and accepted QObject parent. At Report's model call and `0x140645030`, record fresh S/D, `D+0x68/+0x2a/+0x30/+0x48/+0x58`, selected branch and callback returns. If `0x140645320` or `0x140646370` runs, record allocation/constructor result, store, `SessionRoot` creation, `appendChild` return, later replacement and DOM state. At accepted Close, bind fresh S+0x30 reads and D's deletion order against parent child deletion. A null Close slot requires an earlier death/rebind witness.
3. Keep observation receipts tied to the original PE identity and actual call/return boundaries. A synthetic slot token, constructor default, DOE output fixture or post-Save viewer result is not an occurrence witness.

## Proposed guards and tests when implementation is attempted

- Preserve `SfOprReport` public Open/Save/Close refusal and the diagnostic slot's `Unknown` default until a source-owned D and admitted path exist. A standalone model may accept an explicitly qualified D/DOM context, but must expose that it is a diagnostic prefix and cannot report public Report completion.
- Unit-check the local null-slot sequence with an injected DOM seam: construct from current `D+0x48`, publish `D+0x30`, call attachment with current `D+0x58`, and reread the slot. Check the existing-nonnull path skips both construction and attachment. Keep `0x140646370` as a separate producer because its nonnull-node arm can overwrite `+0x30` without the lazy accessor's null guard.
- Test a failed/null `createElement` or append result, plus a changed `D+0x58`/`D+0x48` between documented boundaries, without assuming rollback or successful XML mutation. Any claimed failure semantics must first be qualified from Qt/native evidence; otherwise stop at the call/result boundary.
- Use a distinguishing same-instance integration fixture only once the original occurrence exists: compare current slot identity, exact `SessionRoot` parent/child relation and count, serialized Save effect, then Close release order. Existing DOE `SessionRoot` tests exercise a different owner and are not Report acceptance evidence.
