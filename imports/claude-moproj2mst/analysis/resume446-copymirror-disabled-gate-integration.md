# CP446 CopyMirror View-owner disabled-gate integration

CP445's source and PE-bound evidence established that the original `140e23a00` plane builder tests actual View Settings flag 1 and either flag 2 or 3 before allocating a plane. Its caller `140e23490` still writes parsed fields into fixed `0x108`-stride records after that builder returns; the collection's allocated-slot extent stays zero. The current port had treated requested input lines as the actual plane count and refused private Save even for this source-closed disabled-gate path.

CP446 added a fixed 128-record mirror owner inside each actual `View` in `viewer.cpp`, with constructor defaults and read-only snapshots from the recovered `141249140/1412479e0` functions. The private importer uses existing lazy `viewOf` and `settingsOf` ownership, refuses missing Settings, keeps gate-true geometry construction guarded, and on the false gate applies the caller's fixed-index `+0x104`, `+0xe0/+0xe8/+0xf0`, `+0xc0/+0xc8/+0xd0` and active-flag writes. It applies parsed flags in a second pass, clears record links when disabled, restarts fixed slots for repeated entries, and refuses the first record beyond capacity while retaining earlier writes. Actual Save and object construction read the View-owned allocated-slot extent. The legacy `viewerMirrorPlanes` vector remains solely as a conservative synthetic private-test guard; production import no longer writes it. Public CopyMirror operation admission and positive-count serialization remain guarded.

An integrated private regression calls the class's load, post-load and `saveAfterFiles` through the existing operation slots using an actual bound View and disabled XML display settings. Two positive input rows populate record fields and flags, yet Save captures a `mirrormerge.ini` prefix with no `MIRROR_MERGE` block because the native extent remains zero. A second post-load with empty INI verifies old requested counts do not resurface. The earlier private L5 test's expected count of two was contradicted by newly recovered gate-true behavior; it now verifies the positive builder remains unsupported before caller record writes. Existing CopyMirror output-open failure tests still pass.

Independent review found and root fixed one stale-sidecar defect in the first integration. After that correction, the two focused MDT tests passed.
