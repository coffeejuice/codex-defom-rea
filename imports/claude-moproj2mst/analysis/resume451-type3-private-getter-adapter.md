# CP451 private DefOptModel value adapter

CP451 adds a private `Type3OptimizerDefOptView` over the existing prepared `Type3OptimizerScalarState`. It exposes the CP450-confirmed scalar values, signed index/nullable NUM_CON row access, region count, and exact `Selected Object` fallback for invalid region-name indices. A prepared row retains classifier result at `value00` and parser field1 at `value04` as different values. The adapter does not represent the native row's uninitialized `+0x10` double, Qt list sharing/copy-on-write, allocation errors or actual `SUB+0x28` ownership. It is not called by public Type3 Open, ShapeOptim load, GEO loading or Save.

The new test exercises default and changed scalars, unequal classifier/tag values, signed invalid and valid row indices, ordered region names, and the invalid-name fallback. It verifies the private value projection; it does not test ShapeOptim's original dispatch on row `+4`. Independent source review found two test harness omissions (namespace and `main`), which were fixed before the selected build; no remaining source finding was reported.
