## Numeric branch is closed in its existing scope

`simcontrol300.cpp:668-682` implements `normalizeCgAtOpen`, source140ed01b0. It returns immediately unless solmtd==2. For a non4 parameter count it assigns the four defaults, then validates fields0/1/3 using `_mm_cvttsd_si32` (`:38`), preserving accepted source doubles rather than rounding the model. Field2 is not gratuitously normalized. The current boundary test exercises these distinctions, including the source's indefinite conversion result for NaN/Inf/overflow.

The retained300 contract places that callback after actual editor construction and page Fill: constructor140eb26f0 →fill140eb5630 →page dispatcher140eb80c0 →iteration140ec19f0 →checked-CG callback140ed01b0. `loader_l3.cpp:664-685` deliberately reaches this normalization only on its explicit legacy no-bound-Session path. On the bound path it calls the actual Session factory and refuses6504abb0 first.

Moving the supported arithmetic into public Session Open before palette/setup would change original mutation order and the model after a failed constructor. The Session test's unchanged solmtd_p array would correctly fail. Adding another scalar edge test would be a regression choice, not a new source-supported implementation increment.

The separate legacy Save refusal140eb5180 is also not a free arithmetic branch. The retained source requires the actual current editor, ordered page Apply, cleanup/notifications/model publication and view effects. An isolated filled numeric snapshot does not supply those native owners or allow bypassing the missing constructor.
