# CP474 private Type3 .OPT late manager and region sections

CP474 connects the CP473 typed section planners to the existing private Type3 `.OPT` Save attempt. After successful open, fixed prefix, scalar/group attempts and prepared rows, the new profile calls the already implemented `doe::Model::unlinkedVars()` once. That call reindexes every manager variable, including linked entries, before its returned list is counted. The count planner sends the original `DOE_PAR` label, signed count, each number from 1 through count with its fixed suffix, and the final standalone `endl` through typed sink operations. Only after that final event returns does the region view read its count. Region rows are then fetched and inserted one at a time as prepared QString `Opt/` + name + `.GEO` events, each followed by `endl`. The typed profile ignores the legacy prepared count/region fragment fields so they cannot be emitted twice.

Failed open assigns the existing path-bearing diagnostic and returns false without scanning the manager. Throws in preceding rows also leave the manager untouched. A throw in the count section preserves the manager's completed reindexing but prevents region and later attempts; the streaming region helper prevents a later name getter after an earlier row event throws. Ordinary insertion and close statuses remain ignored. The attempt returns false on both ordinary paths and its caller continues after that false return. The new overload is private; the m2m C ABI and public Type3 guard are unchanged.

Independent source review found no implementation blocker and prompted stronger assertions for the exact manager/count/region event subsequence, the direct false return, empty typed sections and missing caller gates. After that correction, a source-stable grouped build and focused `m2m.doe.type3_opt_save_attempt` passed. One source/binary-bound complete launcher ran 385/385 tests: 378 clean, six logged-gap and one logged-difference cases, no skips, incomplete outputs or fixture changes. Historical Save remains 93 SAME/five DIFF. Final source SHA-256 was `a033acddbe68375f7de007b56e17aa4a982a93036088bbbd2bd32267766aee38` over 3,608 files. The earlier CP474 build with weaker assertions was not used as acceptance evidence; `analysis/cp474r-build.json` is the final build receipt.

This is a private state and insertion-order projection, not original Qt execution. Native owner lifetime, Qt QList refcount/failure behavior, QTextStream formatting, codec, QFile bytes, fault unwind and public Type3 Open→Save→Close admission remain unclosed.
