# CP186 connector implementation

The connector now models exactly `[0x13123e,0x13123f)`, byte `5f` (`pop rdi`), and stops at `BeforePrivateReturn` / RVA `0x13123f`, before RET. Default absolute diagnostic stop is 8; 0 through 7 remain available, and 9 is invalid.

`QObjectPrefix::SavedEntryRdi` is created with the qualified caller/prologue frame. Its provenance binds the allocation owner/control block, Report ordinal, task and allocation-time private identities, Qt module hash, initializer entry/save instruction, incoming RDX-to-caller-RDI origin and move, call, and return RVAs. The restored token is the identity of this retained record, not captured register bits or a native parent pointer. A null result means no POP result; it makes no assertion about the unknown native value. The saved record and slot remain present after POP.

All saved-RDI provenance and symbolic stack guards run before resumed mutation. Earlier phases forbid a restored token; CP186 requires that token to identify its own saved record, with live RSP displacement zero. RAX/private and RBX/task predecessor guards admit CP186 while preserving their earlier phase restrictions. The existing full sparse/private flags/root/control-block/version/ownership checks run before each instruction and terminal refusal. POP publishes only a scalar token pointer, RSP displacement zero, and phase. These publications do not allocate or throw. Historical ADD flag effects and CP182 expressions remain separate; no flags, memory, backlinks, parent relationship, RET, or caller continuation are invented.

Focused tests cover success/full snapshot equality after undoing only POP effects, retained saved provenance, all diagnostic budget reductions, same/different/unknown key reentry, CP185 rewind/resume, all earlier flags rewinds, premature restored tokens at every earlier phase, and nonrepair of corrupted provenance on rewind. A 57-case predecessor/terminal corruption matrix includes all retained CP185 corruptions plus absent/foreign/control-block-alias saved provenance, each represented origin field, missing/premature/foreign restored token, and wrong cursor. Snapshot helpers include saved-RDI fields, owner/control block, and restored token. Historical default-terminal expectations and explicit rewind cleanup were updated; explicit CP185 tests continue selecting stop 7.
