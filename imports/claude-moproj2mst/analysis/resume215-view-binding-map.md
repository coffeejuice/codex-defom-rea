## Effects versus deferred delivery

The [concrete setter body](wave3-boolean-open-native-view-140170430.c) first marks a private updating flag. If an old model is attached, it saves the old view position and detaches it. It attaches the new model, clears/rebuilds render and selection holders, invokes view refresh virtuals and current-model virtual work, then clears the flag. For nonnull RDX, it calls `QTimer::singleShot(1000, this, modelUpdated())` at RVA `17085f`. The [timer contract](wave3-boolean-timer-contract.json) finds no equality shortcut or coalescing in this setter: two successful nonnull calls can request two distinct timers. A normal setter return proves its synchronous body returned for that occurrence; it does not prove timer registration succeeded, the Qt event loop delivered the timeout, `modelUpdated()` ran, or downstream editor-selection callbacks completed. A separate timer/event-loop witness is needed for those claims. Likewise, `a7250` can lazy-parse XML and invoke DOE refresh notifiers before `38380`; notifier invocation alone does not prove receiver delivery or parser success.
