The editor300 increment adds remembered step-size and stopping forms under explicit supported-profile guards. Public Save remains refused while the complete editor is uncomposed. Eight new snapshot cases bring that executable to16 cases; the coordinator owns build and test execution.

Step size now captures each numeric line edit and a deep, const-owned temporary DTTYPE curve. The supported branch is3D, KnownC locale, constant DTTYPE without table or owned-object state, and valid initial radio values. Fill preserves the original DTTYPE mutation. Apply follows the original store/validation order and copies the remembered curve only after preceding fields succeed. Invalid and Intermediate remain distinct.

Stopping supports the branch where both MDS combos select none, including missing or undefined stored object numbers. It remembers scalar and rotation text, preserves sequential validation writes, and still converts MDSOBJ4 and executes the tail when that final validator reports Invalid. Save re-runs the rotation scan against the then-current model; it does not reuse a frozen selected object number. Existing selected MDS objects and their callbacks remain unsupported. The unrecovered PDIE warning answer is refused at its original branch point, after preceding TMAX/SMAX writes.

The constructor contract now includes another retained original refresh. After the immediate second stopping/meshing fills, ecb340(0) backs up the model, refills general and step count, copies the model's DTTYPE into the editor, refills step size and iteration, copies environment curves and refills environment/advanced, then restores the model backup. Those later widget snapshots must be preserved even though the model changes are restored. The earlier two-element repeat list alone was incomplete.

The successor is meshing. Review has started on the retained per-object form copy/roundtrip and the separate global remesh singleton. No meshing implementation or complete Save equivalence is claimed. Source hashes, exact addresses, guards and validation limits are retained in the JSON receipt.
