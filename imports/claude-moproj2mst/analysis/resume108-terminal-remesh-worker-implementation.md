## Explicit child and terminal route

Parent Options explicitly select `allowOwnedWorkerTermination=true`, `workerRole=RemeshConversion`, `protocolProfile=RemeshV2`, this executable's own verified image/SHA, an exclusive configured checkout/build scratch leaf, 15-second deadline and default128KiB capture bounds. `prepareOwnedCase` receives only the supervisor-validated new leaf, creates the separate short DEFORM project and retains its physical denial handle. It writes a bounded <=256-byte job with schema, exact selected case and owned short root. The child rejects mismatched schema/case/role/opt-in/nonce, unsupported cases or nonzero unrelated handle, and checks the short project's resolved parent and reparse status. Argv exactly follows the frozen supervisor contract: argc7, role token, opt-in token, decimal case, pipe uintptr, nonce, unrelated uintptr. The child validates its finite case against the shared selection table. Other supplied harness roles retain `th::childMain` behavior; no new public command option exists.

The private Backend validates every remesh request field and modeled errno22 at the actual leaf dispatch. Only then does it write its small diagnostic call ledger, encode the exact live SaveCallState as V2 Boundary (site2/statusC0000417/error22/ordinal1/profile1/proof1), and invoke `TerminateProcess` on **its own current process**. No host CRT invalid-parameter handler or undefined null-FILE printf is used. A publication or endpoint return goes through explicit enum-to-wire failure tags and the existing leaf failClosed/park; the parent rejects such a run via sticky supervisor disposition. The test cannot classify exit status alone as terminal success. It requires valid two-frame transcript, live snapshot, confirmed child stop, no supervisor-requested stop and matching before/after worker image hash.

Qualification retained in receipts: `constructed-remesh-overlay;retained-B133-raw-prefix;candidate-fixed-endpoint;native-default-handler-prelude-unimplemented;no-native-Close-claim`. The adapter-return marker is written only after conversion returns and Session adapter destruction has run. It must be absent for the terminal case. The protocol has no Closed record and the current core has no observed normal native Close call; this test does not invent one or treat adapter destruction/parent scratch cleanup as native Close.

## Lease and raw diagnostics

The physical parent denial handle remains held until the supervisor confirms child stop and invokes `inspectStoppedCase`. Inspection probes write denial while the lease is still alive, captures the full before/after manifest with size/SHA/completeness/error details, retains all changed/added/deleted raw bytes and missing/error markers, and retains all five available actual/expected prefix outputs before comparison assertions. Collector read errors preserve available partial bytes rather than failing before the difference bundle is written. The rewritten project XML and any other incidental raw differences are retained without normalization or assumed historical XML after oracle.

Only then does the fixture destructor close the denial handle and recursively remove its own resolved direct child of `C:/PROBLEM`, after rejecting reparse points in the tree. The parent's receipt checks cleanup and records cleanup error. If OS stop cannot be confirmed, the supervisor's established fail-closed lease retention applies and the test cannot pass or release the locked live case. All protocol/stdout/stderr, job, manifests, complete raw differences, expected/actual prefix bytes, backend ledger and parent receipt remain in the unique configured scratch leaf on both success and failure. This bounded diagnostic retention is intentional; original fixture trees are read-only.
