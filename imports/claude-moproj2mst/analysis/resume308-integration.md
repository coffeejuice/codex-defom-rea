# CP308 private dual-job fake model

CP308 adds a private fake supervisor model for separately owned worker and child jobs. It duplicates a worker-local offered child handle into the supervisor, independently compares PID, creation time, image and job membership, records an occurrence ACK and a separate caller-supplied worker receipt claim, then attempts bounded exact-handle and job cleanup. The API is deliberately simplified for in-memory fakes; no typed live Win32 adapter, authenticated transport, child creation or original/GUI entry is enabled.

Independent review found two containment errors in successive drafts. Zero active-job counts initially allowed both jobs to close while the exact worker wait had timed out; a second case allowed closure while the exact child wait had timed out. The final source retains both jobs until termination is confirmed, both current job counts are zero, the worker exit is confirmed and, when a child handle exists, its exact exit is confirmed. Review also corrected an ACK acceptance overclaim and required failure/nonmembership distinctions in the fake query contract. Final independent review passed the fake-only scope.
