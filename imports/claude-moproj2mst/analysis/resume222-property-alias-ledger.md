## Required ownership/API decisions

1. Lane A must publish a narrow contract for private `GuiModel::step_`, object/material identity keys, and private `Operation` cache. F callers should not receive `DB_STEP_DATA*`, `LLOBJ_DATA*`, or mutable `shared_ptr<GuiModel>` merely to preserve existing field syntax.
2. Heat-treat code needs named commands for dimension, node/object observations, and SimCtrl-to-property copying. A callback wrapper whose result is local is insufficient if a callback can capture an alias; avoid raw pointer and `void*` public seams.
3. Keep the distinction between property payload (`Props::step` / `HeatTransferStepData`), native model step (`GuiModel`), Cogging model (`CoggingProps::model`), and operation cache (`Operation::engineModel`). Each has different ownership and output semantics.
4. Cache cleanup needs a guarded owner token/identity API; Session needs an exact owner comparison. Both must be supported without exposing cache replacement to ordinary consumers.
