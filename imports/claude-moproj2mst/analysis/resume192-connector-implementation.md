# CP192 connector implementation

Implemented the caller spill at QtCore RVAs `[0x13142c,0x131431)`, bytes `48 89 44 24 58` (`mov [rsp+0x58],rax`). The default and maximum absolute flags/epilogue/caller budget is now 14. Historical budgets 0 through 13 retain their cuts. The new phase `BeforePrivateTaskBacklink` derives cursor `0x131431`, before `mov [rax+8],rbx`.

`QObjectPrefix::CallerPrivateSpill` records a symbolic private-allocation token, allocation owner, Report ordinal, public task identity, qualified module and initializer CALL/RET lineage, spill instruction RVA, and both slot offsets. The module is a string view of the static qualification; constructing/moving the record and committing the optional and phase does not allocate. Compile-time assertions in the focused test check nonthrowing record/optional moves and assignment. With live RSP `S+8`, `[RSP+0x58]` denotes `[S+0x60]`; saved RBX, saved RDI and return-slot observations remain distinct.

Admission requires the exact spill record only at the new terminal and forbids premature records in earlier phases. The owner must have both matching stored pointer and matching shared control block. All inherited CP191 validation remains active at the successor, including public task+8 identity/marker, R12, returned/restored registers, XOR state, symbolic stack and return lineage, allocation sizes and identities, sparse zeros, initializer version, widget/shared-null roots, ownership and committed references. Reentry validates the retained state even at a smaller budget. The spill record and phase are published only after complete admission. `private08` stays qualified zero; reverse publication and both completion flags remain false.

Focused test source extends full snapshots with spill values, spill ownership/control block and derived cursor. Added tests cover the precise single-slot transition, all terminal budgets and three task keys, consistent rewind/resume, phase-only rewind refusal, all intermediate budgets, the production default, invalid budgets 15 and maximum size, premature spill at every earlier phase, 18 spill-specific corruption cases at small and full budgets, and the inherited 118-case corruption matrix at both predecessor and terminal. The inherited matrix covers shared-null/control-block/lineage/flags/publication/register and allocation corruption. Expired widget-root refusal is also retained at the new predecessor/terminal. Historical CP191 default coverage now pins budget 13; invalid-budget tests use the new maximum plus one.
