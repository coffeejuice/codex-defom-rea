# CP274 Slice model flag at native +0x258

The canonical `GuiModel(nullptr, 3)` Slice fixture corresponds to a freshly constructed native model whose byte at +0x258 is **zero**. The converter has no stored member for that byte. Its existing `patchModeOf(const GuiModel&)` folds the operation-model value to `true`; this is a prior narrow semantic projection, not a general representation of the flag. A 3D/null-database Slice admission can use the constructor invariant for this canonical, live owner, while retaining refusal for owners whose flag history cannot be established. This report is a read-only mapping and decision; it changes no source or test.

## Converter correspondence and decision

`source/apps/moproj2mst/include/m2m/engine.hpp:149-193` defines `GuiModel`, including the represented +0xd8 `db` pointer at line 184 and +0x25c `f25c` at line 193, but no +0x258 flag member. `src/engine/gui_model.cpp:188-193` constructs `step` and assigns `db(h)` without an editor-style flag transition. `src/engine/viewer.cpp:1525-1529` hardcodes operation-model `patchModeOf` to `true` using the constructor-zero premise. The actual fixture at `tests/mdt/test_viewer_slice.cpp:247-270` creates `GuiModel model(nullptr,3)`, attaches a Slice, then presently expects rebind refusal. `src/engine/viewer.cpp:1665-1677` locates that refusal after object binding. The public `GuiModel` does not expose a flag value to assert in this test, so the native constructor chain and the restricted converter model path are the flag witness; adding a public test seam solely for this byte is unnecessary for this leaf.

For this canonical live model, the native helper reads a valid owner's +0x258 byte (zero), then reads its valid +0xd8 database pointer (null), and returns before collection replacement. A narrowly scoped converter admission of its 3D/null-DB rebind is supported as **result and collection-effect parity** for the Slice gate, provided the existing actual-owner, present-step, and synchronous geometry guards remain in place. No editor-model flag setter is represented or reachable through this constructor-only fixture. Keep database-backed 3D adaptation and foreign/null owners refused. If a future caller can import, mutate, or alias an editor-style flagged model, this constructor proof no longer covers it; represent or otherwise qualify the flag before admitting that profile.

Null database alone makes the *final branch-body result* independent of the flag value: flag 1 stops before the database getter; flag 0 reaches it and then stops on null. It does **not** make the native access trace independent. The native flag read occurs before the database read, and a stale/invalid owner can fault at the flag read even where a converter's `db == nullptr` check would succeed. For the canonical valid owner, both getters are direct, apparently side-effect-free field reads, so omitting the physical byte in the converter does not change the supported Slice collection effect. This does not establish instruction-order, fault, reentrancy, or arbitrary-owner parity. A broad rule of “admit every 3D model with `db == nullptr`” would exceed the evidence.

The planned test can verify two successful rebinds and preserved constructor-only collection/runtime state, but cannot by itself prove the missing byte's value or a naturally reached original GUI occurrence. The static constructor/getter/setter evidence supplies the former for this fixture; original runtime observation and full bind continuation remain separate qualifications.
