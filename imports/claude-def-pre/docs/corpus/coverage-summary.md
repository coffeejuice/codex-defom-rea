## Notes

* Line-start tokens in KEY files that are not in the registry: `DEFORM` (172), `SRFNRG` (60), `AISI` (48), `MATERIAL` (34), `OBJECT` (33), `OITAREPO` (18), `EXTR1` (14), `DIE` (10) … Apart from `SRFNRG` (skipped silently by the reader) these are object/material names and reversed
  strings on data lines, not keywords.
* deformdb keyword names that are not registry names (deformdb's own labels for DB arrays): `DTMP`, `EFEPS`, `EFSTS`, `EPS`, `FRZB`, `HITN`, `HTGN`, `PRZB`.
* DB coverage only covers the node/element keywords that deformdb's typed view decodes (its keyword
  table); scalar and header keywords stored in a DB step are not mapped yet, so the DB column under-reports.
  The Phase 2 oracle (DBREAD + KFWRIT through the original DEF_PRE) will give the full list per step.
